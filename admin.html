Hướng dẫn lấy URL ảnh

Cách dễ nhất để bạn lấy URL ảnh chuẩn
(Khuyên dùng Postimages.org):

  1. Truy cập vào trang web miễn phí:
    https://postimages.org/ (không cần đăng nhập).
  2. Bấm nút Choose Images và chọn bức ảnh từ máy tính của bạn.
  3. Chờ vài giây để web tải lên.
  4. Ở màn hình kết quả, bạn sẽ thấy rất nhiều loại link. Hãy copy dòng có chữ "Direct link" (Link trực tiếp). Ví dụ:
    https://i.postimg.cc/abcxyz/anh-tra-sua.jpg
  5. Mang cái link đó dán vào ô nhập liệu trong Admin của bạn là xong!
